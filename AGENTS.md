# Agent rules for twake-tools

- Decisions: each tool keeps its own `docs/decisions.md` (`cozy-app-*/docs/decisions.md`), mandatory, none at the repo root. Search the log of the tool you change before asking a question or proposing a change; record every decision in the log of the tool it touches (the main one when it touches several, the others in its Scope line), in the commit that applies it (skill `twake-decisions`).
